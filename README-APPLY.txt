۳) big-lama.pt روی دسکتاپ و وب (بجز اندروید):

     حتی بدون GPU (برای غیرفعال‌سازی: --cpu). اگر torch نبود، خودش نسخهٔ
     CPU (~۲۰۰MB) را یک بار نصب می‌کند.
   • اندروید مثل قبل از LaMa ONNX استفاده می‌کند.

     (قبلاً مستطیل کامل ماسک می‌شد و صورت/دستِ چسبیده به متن خورده می‌شد).
   • متن کج: به‌جای پُرکردن کل مستطیلِ چرخیده، فقط جوهرِ حروف ماسک می‌شود.
   • پاراگراف‌های بزرگ: خط‌به‌خط inpaint می‌شوند (قبلاً کل بلوک TELEA
